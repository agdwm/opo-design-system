# opo-button

Botón de acción reutilizable del Design System OPO.

El componente está construido con `Stencil` y `Shadow DOM`, ofreciendo:

- variantes visuales,
- tamaños,
- estados interactivos,
- accesibilidad básica,
- soporte para iconos mediante slots,
- y loaders customizables.

---

## Import

```tsx
import "@opo/components/opo-button";
```

---

## Basic usage

```html
<opo-button> Guardar </opo-button>
```

---

## Variants

El componente soporta distintas variantes visuales:

- `primary`
- `secondary`
- `ghost`
- `destructive`

### Primary

```html
<opo-button variant="primary"> Guardar </opo-button>
```

### Secondary

```html
<opo-button variant="secondary"> Cancelar </opo-button>
```

### Ghost

```html
<opo-button variant="ghost"> Más información </opo-button>
```

### Destructive

```html
<opo-button variant="destructive"> Eliminar </opo-button>
```

---

## Sizes

El tamaño visual se controla mediante la prop `size`.

Valores disponibles:

- `sm`
- `md`
- `lg`

```html
<opo-button size="sm">Small</opo-button>
<opo-button size="md">Medium</opo-button>
<opo-button size="lg">Large</opo-button>
```

---

## Icon buttons

El componente soporta botones icon-only mediante la prop `iconOnly`.

En este modo:

- el label visual no se renderiza,
- el botón mantiene accesibilidad mediante `ariaLabel`,
- y el tamaño visual sigue controlándose mediante `size`.

```html
<opo-button variant="ghost" size="md" icon-only aria-label="Buscar">
  <opo-icon slot="icon-start" name="search"></opo-icon>
</opo-button>
```

> [!IMPORTANT]
> Los botones icon-only deberían proporcionar siempre `ariaLabel` para mantener un nombre accesible.

> [!NOTE]
> En HTML se usa como atributo kebab-case (`icon-only`), mientras que en JSX/TSX se consume como prop camelCase (`iconOnly`).

## Icons

Los iconos se insertan mediante slots:

- `icon-start`
- `icon-end`

### Start icon

```html
<opo-button>
  <opo-icon slot="icon-start" name="search"></opo-icon>
  Buscar
</opo-button>
```

### End icon

```html
<opo-button>
  Continuar
  <opo-icon slot="icon-end" name="arrow-right"></opo-icon>
</opo-button>
```

### Both icons

```html
<opo-button>
  <opo-icon slot="icon-start" name="search"></opo-icon>
  Buscar
  <opo-icon slot="icon-end" name="arrow-right"></opo-icon>
</opo-button>
```

---

## Loading state

La prop `loading`:

- muestra un loader,
- deshabilita interacción,
- y aplica `aria-busy` automáticamente.

```html
<opo-button loading> Procesando </opo-button>
```

### Custom loader

```html
<opo-button loading>
  Guardar
  <opo-icon slot="loader" name="refresh-cw" size="sm" spinning></opo-icon>
</opo-button>
```

---

## Disabled state

```html
<opo-button disabled> Deshabilitado </opo-button>
```

---

## Full width

La prop `fullWidth` hace que el botón ocupe todo el ancho disponible del contenedor.

```html
<opo-button full-width> Continuar </opo-button>
```

---

## Accessibility

El componente incorpora:

- soporte para `aria-label`,
- `aria-busy` automático durante loading,
- botón nativo HTML,
- soporte de teclado nativo,
- y focus management mediante `:focus-visible`.

Los icon-only buttons deberían proporcionar siempre:

```html
aria-label="Descripción"
```

## Public styling API

### Shadow parts

| Part         | Description           |
| ------------ | --------------------- |
| `base`       | Native button element |
| `label`      | Button label wrapper  |
| `icon-start` | Start icon wrapper    |
| `icon-end`   | End icon wrapper      |
| `loader`     | Loader wrapper        |

---

## Props

| Prop        | Type                                                   | Default     | Description                                  |
| ----------- | ------------------------------------------------------ | ----------- | -------------------------------------------- |
| `variant`   | `"primary" \| "secondary" \| "ghost" \| "destructive"` | `"primary"` | Visual variant                               |
| `size`      | `"sm" \| "md" \| "lg"`                                 | `"md"`      | Visual size                                  |
| `iconOnly`  | `boolean`                                              | `false`     | Renders the button as icon-only              |
| `fullWidth` | `boolean`                                              | `false`     | Expands button width to the container        |
| `loading`   | `boolean`                                              | `false`     | Shows loading state and disables interaction |
| `disabled`  | `boolean`                                              | `false`     | Disables the button                          |
| `ariaLabel` | `string`                                               | `undefined` | Accessible label                             |
| `type`      | `"button" \| "submit" \| "reset"`                      | `"button"`  | Native button type                           |

---

## Slots

| Slot         | Description          |
| ------------ | -------------------- |
| default      | Button label/content |
| `icon-start` | Start icon           |
| `icon-end`   | End icon             |
| `loader`     | Custom loader        |

---

## Notes

- El componente utiliza `Shadow DOM`.
- Los estilos internos están desacoplados mediante Design Tokens.
- Las transiciones utilizan motion tokens compartidos del sistema.
- Los icon buttons utilizan un pequeño optical alignment para mejorar centrado visual de iconos.
- El componente utiliza `button` nativo para mantener comportamiento y accesibilidad estándar.
